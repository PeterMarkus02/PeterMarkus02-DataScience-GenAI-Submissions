# IB2AD0 – Titanic EDA (Session 2 seminar practice)

Exploratory Data Analysis (EDA) of the Titanic passenger data (891 passengers, 12 columns).

## What the notebook does
1. **Structure** – shape, column types, basic statistics.
2. **Issues** – missing values (and whether they are random), duplicates, Fare = 0, outliers, odd ages, messy text (Cabin, Name, Ticket).
3. **Patterns** – survival % by sex, class, age band, family size, port, cabin and fare, plus new features (FamilySize, HasCabin, Title).
4. **Conclusions** – main findings and the business takeaway.

## Files
- `titanic_eda.ipynb` – the code, with comments and outputs
- `titanic.csv` – the data

## How to run
Open `titanic_eda.ipynb` in Google Colab and run all cells. The second code cell asks you to upload `titanic.csv` if it is not already in the session.
